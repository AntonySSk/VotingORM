# VotingORM - Система обліку результатів голосування

Консольний застосунок на мові **C++20**, що реалізує роботу з реляційною базою даних SQLite за допомогою бібліотеки **`sqlite_orm`**, паттерну **Repository** та механізму **транзакцій**.

## Вимоги для збирання
* Компілятор C++ із підтримкою **C++20** (наприклад, MSVC у Visual Studio 2026).
* Система збирання **CMake** (версія 3.21 або новіша).
* Пакетний менеджер **vcpkg** у режимі маніфесту.

## Структура проєкту
* `include/` — заголовочні файли (`Candidate.h`, `Vote.h`, `ICandidateRepository.h`, `CandidateRepository.h`).
* `src/` — головний файл програми (`main.cpp`).
* `vcpkg.json` — маніфест залежностей (`sqlite3`, `sqlite-orm`).
* `CMakeLists.txt` — конфігурація збирання CMake.

## Інструкція зі збирання та запуску (у Visual Studio / PowerShell)

1. Клонуйте репозиторій або відкрийте папку проєкту.
2. Налаштуйте конфігурацію CMake із підключенням toolchain-файлу vcpkg (якщо використовується інтеграція vcpkg у Visual Studio, це відбувається автоматично).
3. Зберіть проєкт через систему збирання CMake.
4. Запустіть скомпонований виконуваний файл (`VotingORM.exe`).
